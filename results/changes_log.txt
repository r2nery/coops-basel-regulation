# CHANGES LOG  (deviations from paper1_v5.ipynb)

1. Cooperative classification
   change: tcb-based, institution-stable (modal tcb per codigo). Primary group = b3S singular cooperatives; non-coops = non-b3; b3C centrals excluded from the comparison.
   reason: Original used (tcb startswith b3) OR (name contains 'COOPERAT'), per-row. The OR-name clause pulled Banco Cooperativo Sicredi (tcb=b1, a bank) into coops in later quarters only, double-counting one institution and breaking the time-invariance the design assumes (it appears as both coop and non-coop). tcb is the regulator's own consolidation type and is stable. This reconciles 1198+762->1959 and 168+483->650.

2. Singular vs central
   change: Centrals (b3C) dropped from the main comparison; only retail singular cooperatives (b3S) enter the coop group.
   reason: The original main sample pooled singulars with ~37 wholesale centrals (high-capital infrastructure entities) and called them all cooperatives, while the heterogeneity section silently excluded the centrals via a 38-row hardcoded list. tcb makes the split principled and the hardcoded EXCLUDE list unnecessary. Expect the headline Basel gap to move toward the singular (Sicredi-dominated) value.

3. Standard errors
   change: Clustered by institution (codigo), reported alongside HC3.
   reason: 650 institutions observed up to ~32 quarters each are serially correlated within unit, and the treatment is assigned at the institution level; HC3 treats all ~15,000 rows as independent and understates SEs. Consensus is to cluster at the most aggregate feasible level (Cameron & Miller 2015; Abadie et al. 2017).

4. Cost-to-income denominator
   change: Operating income (net interest income + fee income) instead of gross intermediation revenue; both reported (cti vs cti_gross).
   reason: The original denominator (gross intermediation revenue, line a) produces a 2.97 ratio for non-coops, which is not a meaningful cost-to-income figure; some institutions have small or negative gross revenue. Net operating income is the standard banking denominator and is far more stable.

5. Winsorization scope
   change: Winsorize within the analysis sample, not the full panel.
   reason: The original set 1/99 bounds on the full panel, which is dominated by simplified-method institutions that never enter the analysis; the bounds should come from the analysed population. Where you winsorize materially moves estimates.

6. Duplicate (codigo,date) rows
   change: Deduplicate every source: drop exact duplicates, then collapse remaining key-dups keeping the most-populated row.
   reason: The assets module carried ~1,354 duplicate (codigo,date) rows (vs 3 elsewhere) that the original silently dropped via keep-first; an arbitrary pick can bias credit/provisioning outcomes. See [DEDUPE] in diagnostics for exact and conflicting counts.

7. CEM coarsening size
   change: Size quintile from each institution's median log-assets over the period, not the entry-quarter snapshot.
   reason: drop_duplicates('codigo') kept the first (earliest) quarter's size bin; typical size is more representative for matching.

8. Standardized differences
   change: Denominator sqrt((var_t+var_c)/2) (Austin 2009; Stuart 2010).
   reason: Original used an n-weighted pooled SD; the matching literature uses the simple average of group variances so the metric does not depend on group sizes.

9. Per-outcome N
   change: Reported for every coefficient.
   reason: Provisioning runs on ~66% coverage (provisions/gross credit missing for a third of rows); this should be visible, not implied by 'roughly 15,004'.
